# REGLA N.º 1 — INVIOLABLE

Ragnarok Vita es un proyecto de PORT NATIVO de Ragnarok Online para PlayStation Vita.

NO es un remake, clon, reinterpretación ni un juego nuevo inspirado en Ragnarok.

Toda decisión técnica debe perseguir la adaptación de una implementación existente del cliente Ragnarok Online y sus sistemas a PS Vita mediante código fuente legalmente reutilizable.

Se deben preservar, en la medida técnicamente viable, los formatos, recursos autorizados, mapas, animaciones, comportamiento, interfaz y mecánicas originales Pre-Renewal.

La beta 0.1 es únicamente una prueba técnica de hardware, no el modelo de arquitectura que debemos seguir indefinidamente.

A partir de ahora:

1. Priorizar el análisis y portabilidad de clientes existentes.
2. Identificar componentes originales o compatibles que puedan trasladarse a VitaSDK.
3. Adaptar esos componentes al hardware ARM de PS Vita.
4. Resolver la ejecución offline sin depender de un servidor externo.
5. No desarrollar sistemas imitativos desde cero como sustitutos del port.
6. Documentar cualquier impedimento técnico o legal antes de proponer una alternativa.

**Si una solución implica abandonar el port y construir una copia del juego, se debe rechazar esa solución y buscar otra vía de portabilidad.**

Esta regla tiene prioridad sobre cualquier fase anterior del proyecto y debe regir todas las futuras sesiones de Codex que trabajen en este proyecto.
